# RGI-CARD Database Installation

This document describes how to install and configure the **CARD (Comprehensive Antibiotic Resistance Database)** database required by **Module 04 – Read-based Resistome** of the ResistoMeta pipeline.

The installation procedure is designed specifically for this pipeline and should be followed exactly to ensure that the RGI BWT workflow can locate its local database reproducibly.

------------------------------------------------------------------------

## Overview

Module 04 uses the **Resistance Gene Identifier (RGI)** BWT workflow to identify antimicrobial resistance genes (ARGs) directly from host-depleted sequencing reads.

The RGI workflow requires a locally installed CARD database.

The database must be installed at the **root of the ResistoMeta repository** as:

``` text
ResistoMeta/
├── localDB/
│   ├── card.json
│   ├── card_reference.fasta
│   ├── card_reference_all.fasta
│   ├── loaded_databases.json
│   └── bwt/
│       └── ...
├── raw_data/
├── config/
├── databases/
├── scripts/
├── results/
├── logs/
└── ...
```

> **Important:** RGI's `--local` option looks for `localDB/` relative to the **current working directory**. Therefore, the commands below must be run from the **ResistoMeta repository root**.

## 1. Activate the RGI environment

``` bash
cd ResistoMeta
conda activate rgi_env
```

## 2. Download the CARD database

From the repository root:

``` bash
wget https://card.mcmaster.ca/latest/data
```

Extract the CARD JSON:

``` bash
tar -xvf data ./card.json
```

This creates:

``` text
ResistoMeta/card.json
```

## 3. Generate the RGI CARD annotations

``` bash
rgi card_annotation -i ./card.json
```

This generates the RGI-compatible CARD annotation FASTA file(s), with filenames containing the CARD/RGI database version.

For example:

``` text
card_database_VERSION.fasta
card_database_VERSION_all.fasta
```

Use the filenames generated by this command in the next step.

## 4. Load the CARD database

Still from the **ResistoMeta repository root**:

``` bash
rgi load \
  --card_json ./card.json \
  --debug \
  --local \
  --card_annotation ./card_database_VERSION.fasta \
  --card_annotation_all_models ./card_database_VERSION_all.fasta
```

Replace `VERSION` with the version contained in the actual filenames generated in Step 3.

Because `--local` uses the current working directory, the database will be installed under:

``` text
ResistoMeta/localDB/
```

## 5. Verify the installation

From the repository root:

``` bash
rgi database -v --local
```

A successful installation should report the CARD database version, for example:

``` text
4.0.2
```

You can also verify the database files:

``` bash
find localDB -maxdepth 2 -type f | sort
```

At minimum, the output should include:

``` text
localDB/card.json
localDB/card_reference.fasta
localDB/card_reference_all.fasta
localDB/loaded_databases.json
```

The `bwt/` directory and its index files are generated when the RGI BWT workflow is first run.
